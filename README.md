# Secure Password Manager

A password management application built using Python to securely store and manage user credentials.

## Features

- Store passwords securely
- Database integration
- Password management system
- Encryption key handling
- Backend and template structure
- User-friendly interface

## Technologies Used

- Python
- HTML
- Database (SQLite/MySQL)
- File Handling

## Project Structure

- `app.py` → Main application logic
- `database.db` → Database storage
- `schema.sql` → Database schema
- `templates/` → HTML templates
- `static/` → Static files
- `filekey.key` → Encryption key handling

## Purpose

This project was created to practice backend development, database management, and security-related programming concepts.

## How to Run

1. Install required dependencies
2. Run the application

```bash
python app.py
